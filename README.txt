================================================================================
           AI Studio Audio Splitter Pro Max - Portable Standalone
================================================================================

Yeh ek complete standalone AI Audio Stem Separation software hai.
Isme kisi bhi external dependencies (Python, PyTorch, FFmpeg) ki alag se 
zaroorat nahi hai. Sab kuch is folder me pehle se bundled hai!

KISI BHI COMPUTER ME KAISE CHALAYE:
----------------------------------
Option 1 (Recommended - 1 Click Setup):
  1. 'Install.bat' par double-click karein.
  2. Option 1 chunein (Standard Install).
  3. Desktop par 'AI Audio Splitter Pro Max' ka icon aa jayega.
  4. Ab bas Desktop icon par double-click karke app ko use karein!

Option 2 (Direct Portable Run):
  - Direct 'AudioSplitterPro.exe' par double-click karein.
  - App bina install kiye turant chalne lagegi.

FEATURES:
---------
- 11 AI Demucs Models (4-stems & 6-stems: Vocals, Drums, Bass, Piano, Guitar, Other)
- YouTube URL direct audio separation & Local file batch upload
- Instrumental & Reconstructed Full Mix generation
- WAV 16-bit, WAV 24-bit, FLAC, MP3 320kbps, MP3 192kbps export
- Bundled FFmpeg & PyTorch Engine
- 100% Offline-ready stem separation

Uninstall:
- 'Uninstall.bat' par double-click karein.
